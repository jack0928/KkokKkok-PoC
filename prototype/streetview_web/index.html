01

비교할 사진과 주소

주소 검색은 원하는 실내·층을 보장하지 않습니다. 정확한 실내 사진은 특정 거리뷰로 지정하세요.

지정한 파노라마만 요청합니다. API에서 제공하지 않으면 다른 장소로 대체하지 않습니다.

0° 북90° 동180° 남270° 서

같은 촬영 지점에서 네 방향을 봅니다. 다른 촬영 위치 네 곳을 찾는 기능은 아닙니다.

서버 설정을 확인하고 있습니다.

02

분석 진행

  1. 사진 검증·분석본 생성
  2. 파노라마 확인·네 방향 거리뷰 요청
  3. DINOv2 검색 유사도 계산
  4. DISK·LightGlue·기하 검증

사진과 주소를 입력하면 시작할 수 있습니다.

결과를 읽는 기준

검색 유사도는 같은 장소일 확률이 아닙니다. 초록 선은 기하 검증 통과점 중 최대 60개이며, 올바른 연결을 보장하지 않습니다.

이미지·벡터·결과는 영구 보고서로 저장하지 않습니다. 결과는 서버 메모리에 최대 5회 보관되며 서버 종료 시 사라집니다. 기존 8765 회차 목록에는 추가되지 않습니다.
