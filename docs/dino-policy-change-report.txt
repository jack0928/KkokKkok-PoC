DINO 탐지·검토 개편 보고서 (2026-11-02)

기존: 실내 기본 목록에 컵·병·의자·식물 등 일반 물체가 포함되고, GPT는 흔한 고정 구조물도 useful로 보존했다. 보존할 자료와 강조할 단서의 구분이 부족했다.
변경: 공통 목록을 기본 사용한다. 건물 외관, 입구, 발코니, 계단, 조형물, 벽화, 분수, 탑, 매장 로고, 호수, 해안, 절벽, 산을 탐지한다. 실내/실외 목록은 선택 설정으로 유지한다. OCR 탐지·인식 규칙은 변경하지 않았다.

새 파이프라인:
공통 목록 → DINO → 동일 레이블 bbox 중복 정리 → 객체별 crop → GPT 객체 일치 검증 → 관찰 근거 및 규칙 선택 → 서버 등급 계산 → 주요 단서/배경 비교 자료/판단 보류/제외 화면.

중복 정리: 같은 레이블이며 IoU 0.85 이상인 후보 중 높은 탐지 점수를 유지한다. 제거 후보는 duplicateDetections에 보존하고 화면에서 확인 가능하다. 다른 이름으로 탐지된 동일 물체는 이 방식으로 제거하지 않는다.

GPT: 영어 지시문을 사용한다. 탐지 레이블을 정답으로 믿지 않고 crop 안 실제 객체와 먼저 비교한다. 명백한 불일치는 irrelevant/not_useful, 불명확하면 unknown/uncertain으로 판단하도록 요구한다. 모양·재질·배치 근거 없이 독특함이나 장소 정체성을 추측하지 못하게 한다. 문자 의미는 OCR만 담당한다. 실제 준수율은 검증되지 않았다.
새 프롬프트 버전: object-fusion-v5-verified. 모델은 기존 OPENAI_MODEL 설정을 사용한다. DINO 모델과 점수 기준은 유지한다.

화면: standard_fixed_structure, generic_view, generic_nature, regional_style, portable_context는 배경 비교 자료로 접는다. 통합 bbox 화면은 기본적으로 해당 DINO 배경 자료를 숨기고 체크박스로 포함한다. 판단 보류 및 제외 원본은 보존한다. 주요 단서도 실제 위치 식별을 검증한 정답은 아니다.

기존 기록: 모델 응답·좌표·위험도는 재분석하거나 덮어쓰지 않는다. 화면 분류는 저장된 규칙 ID에 따라 적용된다. 규칙이 없는 이전 결과는 판단 보류 표시로 다룬다.

한계: OCR 중복은 문자 해석 금지 지시로 억제하며 OCR와 DINO의 의미적 중복을 서버가 완전히 판별하는 기능은 아니다. 넓은 자연 영역이나 로고의 bbox 정확도는 별도 확인이 필요하다. PDF 재해석 대신 기존 single-cue-v1 규칙표를 바탕으로 탐지 대상을 구성했다. 누적 분석, 위험 점수 정책, 새 모델 학습은 추가하지 않았다.

검증: 타입 검사·린트·빌드 결과는 작업 완료 메시지 참조. 실제 DINO 추론 및 유료 GPT 호출은 실행하지 않았으므로 정확도 향상을 실측했다고 주장하지 않는다.
