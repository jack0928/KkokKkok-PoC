단서 누락 개선 보고서 (2026-11-02)

1. 작은 글자 누락
문제: 분석본 전체를 한 번만 OCR하여 작은 깃발·버스 글자를 놓칠 수 있었다.
수정: 원본이 있으면 방향 정규화·메타데이터 제거 후 최대 3072px로 준비한다. 전체 검사와 1024px 크기, 약 20% 겹침 분할 검사를 수행한다. 동일 위치의 동일 문자열은 합치고, 다른 읽기는 후보로 보존한다. 모든 좌표는 전체 이미지 정규화 좌표로 환산한다.

2. 실패 원인을 확인하기 어려움
수정: 검사별 원문·좌표·입력 크기, 판독되지 않은 문자 영역, 읽기 불일치를 저장하고 OCR 화면에서 확인한다. GPT 관찰→검색어→탐지 개수→검토 연결도 화면에 표시한다.

3. DINO 검색어와 레이블 불일치
문제: 검색어와 탐지 레이블이 정확히 같아야 연결되었고, 같은 레이블 하나가 있으면 다른 위치 탐지도 생략했다.
수정: 최대 4개 검색어를 각각 요청하고 요청 ID로 출처를 추적한다. 레이블 문자열이 달라도 해당 요청의 후보로 검토할 수 있다. 같은 이름의 기존 객체가 있어도 추가 검색을 생략하지 않는다. 실제 연결은 GPT crop 검토를 거친다.

4. 창문 배열 누락
수정: 기본 목록에 창문·창틀을 추가했다. GPT에는 개별 창문뿐 아니라 외벽 영역과 창틀·격자 배열을 관찰하도록 지시했다. 외벽 bbox를 패턴 근거로 쓰는 경우 개별 창문 경계와 구분해 설명한다. 탐지된 외벽 하나를 crop하여 창문·창틀을 한 번 더 탐지하고 원래 이미지 좌표로 환산한다. 외벽이 없으면 이 단계를 생략한다.

한계: OCR 처리량과 DINO 실행 시간이 증가한다. 4개를 넘는 추가 검색어는 생략될 수 있다. 고정 목록은 창문, 창틀, 건물 외관, 입구, 발코니, 계단, 조형물, 벽화, 분수, 탑, 매장 로고, 호수, 해안선, 절벽, 산이다. 원본 픽셀에 없는 글자를 복원하지 않는다. 실제 사진·유료 GPT 검증 없이 정확도 향상을 보장하지 않는다. 기존 저장 결과는 재분석하지 않는다.

검증: 타입 검사·린트 통과. OCR 분할 일정·좌표 범위·서로 다른 읽기 보존, DINO 레이블 불일치 연결·재시도 재사용은 모의 입력으로 확인했다. 실제 사진 추론 및 유료 GPT 호출은 실행하지 않았다. 추가 DINO는 검색어별 최대 4회와 외벽 crop 최대 1회다.


2026-11-03 추가: OCR 채택 판단 구조 개선
문제: 동작 21 같은 노선 표기의 유지·제외가 바뀌고, 일반 편집 자막도 보존 가치가 있다는 이유로 useful이 되었다.
수정: 영어 프롬프트를 문자 출처 → 판독 상태 → 정보 종류 순서로 교체했다. GPT는 세 분류와 근거를 반환하고, 서버가 채택 여부와 규칙을 적용한다. 명확한 교통 노선 표기는 이동 물체여도 간접 단서로 유지한다. 일반 자막·진료 항목·가격·운영시간만 있는 안내는 제외한다. 판독이나 출처가 불명확하면 보류한다. 위치 정보를 포함한 자막은 자동 제외하지 않고 보류한다. 버스 광고의 상호는 고정 장소 식별자로 취급하지 않는다.
OCR 판단에 기존 GPT 개별 관찰을 보내지 않아 판단 영향을 줄였다. 같은 표지의 인접 글자만 묶고, 겹치는 대안 판독을 이어 붙이지 않도록 명시했다. 원문은 유지·제외와 무관하게 보존한다.
버전: ocr-fusion-v3-structured. 기존 결과는 당시 버전으로 유지하며 재분석하지 않는다. 결과 캐시는 추가하지 않았다. GPT의 출처·판독·종류 분류 자체에는 변동이 남을 수 있다. 유료 반복 검사는 별도로 수행해야 한다.


2026-11-03 추가: 비문자 OCR의 유지 그룹 혼입 방지
문제: 버스 지붕 구조물의 W— 오인식을 GPT가 동작 21 노선 표기와 묶었다. 설명에는 오인식이라고 적었지만 그룹 전체가 route로 유지되었다.
수정: 그룹을 만들기 전에 모든 OCR ID를 실제 문자 / 비문자 오인식 / 판독 보류로 검증한다. 서버는 비문자·보류 ID를 그룹에서 분리하고 각각 제외·보류 항목으로 저장한다. 원래 문자열·좌표와 GPT 원본 응답은 보존한다. 화면에 항목별 검증 근거를 추가했다. 같은 버스에 있다는 이유로 같은 표기로 묶지 못하도록 영어 프롬프트를 보강했다.
버전: ocr-fusion-v4-line-validation. 기존 결과는 수정하지 않으며 새 검토에 적용한다. GPT가 비문자 자체를 문자라고 잘못 판정하는 경우는 여전히 가능하다. 이번 작업에서는 유료 재검사를 실행하지 않았다.
